# Система управления заказами



Данный проект реализует простую систему управления заказами с использованием SQLAlchemy для работы с базой данных и Pytest для тестирования.



## Особенности:

- **Модели данных**: `Order` (Заказ) и `OrderItem` (Позиция заказа).

- **Репозиторий**: `OrderRepository` для выполнения CRUD-операций и бизнес-логики.

- **Внешнее взаимодействие**: Имитация вызова внешнего API для расчета стоимости доставки (`calculate_delivery_cost`).

- **Обработка ошибок**: Использование кастомных исключений.

- **Тестирование**: Полное покрытие методов репозитория с использованием `pytest`, `pytest-httpx` (для мока HTTP запросов) и `pytest-cov` (для отчета о покрытии).

- **Транзакционность**: Обеспечена механизмом сессий SQLAlchemy. При ошибке создания заказа (например, ошибка API доставки), транзакция откатывается, и заказ не попадает в БД.



## Установка и запуск



1.  **Клонируйте репозиторий (или создайте файлы вручную):**

    



bash



    git clone 



    cd order_management



    Если вы создали файлы вручную, убедитесь, что структура проекта соответствует описанной выше.



2.  **Создайте виртуальное окружение (рекомендуется):**

    



bash



    python -m venv venv



3.  **Активируйте виртуальное окружение:**

    -   На Windows: `.\venv\Scripts\activate`

    -   На macOS/Linux: `source venv/bin/activate`



4.  **Установите зависимости:**

    



bash



    pip install -r requirements.txt



## Запуск тестов и генерация отчета о покрытии



Для запуска всех тестов и генерации отчетов о покрытии кода выполните следующую команду в корневой директории проекта:



bash



pytest tests/ --cov=app --cov-report=term-missing --cov-report=html



-   `pytest tests/`: Запускает все тесты в директории `tests/`.

-   `--cov=app`: Включает модуль `pytest-cov` для измерения покрытия кода в директории `app/`.

-   `--cov-report=term-missing`: Отображает краткий отчет о покрытии в консоли, включая строки, которые не были покрыты.

-   `--cov-report=html`: Генерирует подробный HTML-отчет о покрытии в папке `htmlcov/`.

## Контрактный тест для внешнего API



В `OrderRepository` реализован метод `calculate_delivery_cost`, который имитирует взаимодействие с внешним API доставки.

Тесты в `test_repositories.py` (`test_calculate_delivery_cost_success`, `test_calculate_delivery_cost_api_http_error`, `test_calculate_delivery_cost_api_network_error`, `test_calculate_delivery_cost_api_bad_response_format`, `test_calculate_delivery_cost_api_negative_cost`) проверяют "контракт" этого API:

- Успешный ответ (статус 200, корректный JSON с `cost`).

- Обработка ошибок HTTP (например, 500).

- Обработка сетевых ошибок (таймаут, отказ соединения).

- Обработка некорректного формата ответа (отсутствие поля `cost`).

- Обработка невалидных данных в ответе (отрицательная стоимость).



Эти тесты гарантируют, что система правильно реагирует на различные сценарии взаимодействия с внешним сервисом, даже если он недоступен или возвращает некорректные данные.
