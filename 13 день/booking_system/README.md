# Система бронирования отелей

Учебный проект сервисного слоя для управления бронирования номеров в гостинице с поддержкой промокодов и ограничений с использованием паттерна.
**Strategy**.

## Основные технологии
- **Python 3.10+**
- **Pydantic V2** (для валидации данных)
- **Pytest + Pytest-cov** (для тестирования и проверки покрытия кода)

## Как установить зависимости

bash

pip install -r requirements.txt

## Как запустить тесты
Запустите команду из корня проекта:

bash

pytest

Для проверки покрытия кода тестами:

bash

pytest --cov=src tests/
